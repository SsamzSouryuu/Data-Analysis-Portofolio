# Supermarket Sales Analysis

## Overview

This project analyzes supermarket sales data to identify sales patterns
and understand performance across categories, sub-categories, products,
customers, regions, and time periods.

## Objective

The objective of this project is to explore the dataset, perform basic
data cleaning, and identify key sales insights using Python and Pandas.

## Dataset

Supermarket Sales Dataset from Kaggle.

## Tools

- Python
- Pandas
- Matplotlib

## Analysis

- Data understanding
- Data quality check
- Missing value analysis
- Duplicate check
- Sales analysis by category
- Sales analysis by sub-category
- Sales analysis by product
- Sales analysis by customer
- Sales analysis by region and state
- Sales analysis over time
- Data visualization

## Key Findings

- Total Sales reached $2,261,536.78.
- Technology was the category with the highest total Sales.
- Phones was the sub-category with the highest total Sales.
- Canon imageCLASS 2200 Advanced Copier was the product with the highest total Sales.
- 2018 had the highest total Sales, with November being the highest-sales month.
- The dataset contained 11 missing values in the Postal Code column.
- No duplicate rows were found.

## Conclusion

Based on the analysis, there were clear differences in sales performance
across categories, products, regions, and time periods. Technology was
the strongest-performing category, while Phones had the highest total
Sales among sub-categories. The analysis also showed that 2018 had the
highest annual Sales, with November being the strongest month.
